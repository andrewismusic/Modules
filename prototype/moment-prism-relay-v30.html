    Button combinations

    Encoders (Moment, Prism)

    • Tap: show and latch the second parameter (pink)
    • Hold Shift: show all second parameters
    • Press and hold, then turn: adjust the other layer for a moment
    • Random + tap: include or exclude in Random
    • Bypass + tap: reset to default
    • Random + turn: upper random limit
    • Random, then Shift + turn: lower random limit

    Keys (Moment, Prism)

    • Random, Bypass: act on release
    • Shift + double-tap Random: shuffle assignments
    • Shift + double-tap Bypass: initialize
    • Shift + hold Bypass 3 s: settings (Bypass keeps, Shift cancels)
    • Random + Bypass: reset assignments
    • Shift + Random + Bypass: full random ranges

    Moment

    • Freeze: latch on or off
    • Shift + Freeze: momentary
    • Bypass + Freeze: fresh capture
    • Random + Freeze: let Random freeze or release
    • Mode button: Spectral / Loop; Shift + tap: Manual / Rolling

    Prism

    • Order: next order; Shift + Order: resolution

    Relay

    • Shift + Random 1: save; Shift + Random 2: load
    • Shift + Bypass: menu
    • In menus: dial scrolls, Bypass enters, Shift goes back

    Computer keyboard

    • Moment: Q Shift, F Freeze, R Random, V Bypass
    • Prism: W Shift, O Order, N Random, M Bypass
    • Relay: Z Shift, A Random 1, B Random 2, X Bypass
    • Hold a key and click an encoder for combinations
    • Space: play or stop
